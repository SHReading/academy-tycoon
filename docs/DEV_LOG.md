## 8/13 — 미결 2건 해소, P1 착수

Orca 워크트리 재구성 + 작업 0 스캐폴딩 착수.

**막힌 것**: 워크트리를 raw `git worktree add`로 만들어서 Orca UI에 안 잡혔다.
Orca는 자기가 만든 워크트리만 추적하고 기존 git 워크트리를 흡수하지 않는다.
앱 재시작 후엔 워크트리는 살아남지만 안의 Codex TUI는 죽는다는 것도 같이 확인했다.

**해결**: `orca worktree create`로 재생성(`~/orca/workspaces/hackathon/` 아래).
main 하위로 종속시키고 각 워크트리에 Codex를 띄웠다.

**사람이 결정한 것** (3건)
1. **P0 종이 프로토타입은 건너뛴다.** 일정상 P1을 바로 시작. 재미 검증은 P3(8/18)에 몰았다
2. **수강료 1인당 1 → 0.5.** 초안대로면 매출 100/턴에 최고가 강사가 29라 "항상 최대 입찰"이 지배전략
3. **특성 6종 확정.** `MID_CLASS_SPECIALIST` 승인, 콘텐츠 배치도 6종 균등 배분으로 생산

**다음**: 작업 0 완료 확인 → A-1(types.ts + rng.ts) → 병렬 해금

**리스크**: P1 구간(8/12–8/14)의 이틀을 이미 썼다. A-1이 8/14 안에 안 끝나면
P2 하한선(8/17 브라우저 6턴 완주)이 위험하다.
