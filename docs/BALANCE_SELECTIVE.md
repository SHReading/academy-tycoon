# SELECTIVE 아키타입 밸런스 — 결정 요청 (8/20)

10만 판 × 6안. 각 회당 3.5초. 시드 1~100000, 강사 풀 content.
**수치는 아직 아무것도 반영하지 않았다.** `balance.ts`는 원본 그대로다.

## 1. 관찰된 문제

`BALANCE_REPORT.md` 판정 3(아키타입 승률 40:30:30) 실패. 편차 48.0%p, 기준 15%p.

| 아키타입 | 승률 | 폐원률 |
|---|---|---|
| FRANCHISE | 50.1% | 17.1% |
| LEGACY | 30.5% | 8.5% |
| **SELECTIVE** | **2.1%** | **34.3%** |

화면에는 "선발형 — 상위반 성과와 영입에 강합니다"라고 적혀 있다.
심사위원이 세 장 중 한 장을 고르는 구조라 1/3 확률로 이 학원을 잡는다.

## 2. 원인 가설 — 상수가 아니라 구조다

승자는 **점유율**로 정해진다(`game.ts` `winnerOf`). 점유율 = 등록 인원 비중이고,
등록 인원은 지원자에서 나온다(`scoring.ts` ④⑤⑦).

```
지원자 = 300 × (자기지수 ÷ 3사 지수합) × 아키타입 배수
자기지수 = 평판 + 보유 강사 인지도 합 × 2
```

SELECTIVE는 **승리 지표에 직접 곱해지는 자리에서 −10%**(배수 0.9)를 맞는다.
FRANCHISE는 같은 자리에서 +20%다. 두 배수의 차이가 33%이고 6턴 복리로 벌어진다.

반대급부인 상위반 성적 ×1.1은 실적 → 평판 경로로만 승리 지표에 닿는데,
자기지수는 `인지도 합 × 2`가 지배한다. 강사를 적게 가진 SELECTIVE는 이 항에서 구조적으로 진다.
**페널티는 승리 지표에 직접, 보상은 간접으로 붙어 있다.**

## 3. 측정한 6안

| 안 | 변경 | SELECTIVE 승률 | SELECTIVE 폐원률 | 편차 | FRANCHISE / LEGACY 승률 |
|---|---|---|---|---|---|
| 현행 | — | 2.1% | 34.3% | 48.0%p | 50.1 / 30.5 |
| A | 입찰 상한 0.3 → **0.4** | 1.8% | **42.7%** | 45.6%p | 47.4 / 32.3 |
| B | 시작 자금 50 → **70** | 1.8% | **48.8%** | 43.3%p | 45.1 / 34.8 |
| C | 지원자 배수 0.9 → **1.0** | 3.6% | 23.4% | 45.2%p | 48.8 / 31.3 |
| D | 지원자 배수 0.9 → **1.2** | **14.0%** | **5.4%** | **29.8%p** | 43.9 / 28.7 |
| E | C + 시작 평판 45 → **60** | 7.4% | 15.5% | 38.4%p | 45.9 / 33.9 |
| F | 배수 **1.1** + 자금 **70** | 8.9% | 30.1% | 34.0%p | 42.9 / 32.8 |

### 읽어야 할 두 가지

**(1) 자금을 주면 더 빨리 죽는다 — 세 번째 재현이다.**
A(입찰 상한↑) 34.3% → 42.7%, B(시작 자금↑) 34.3% → 48.8%, F도 C 대비 23.4% → 30.1%.
8/14에 상한을 30%→60%로 풀었다가 폐원률이 악화된 것과 같은 현상이다.
여력이 늘면 더 크게 지르고, 낙찰가는 6턴 고정비라 그대로 부채가 된다.
**"돈을 더 준다" 계열은 전부 역효과다. 다시 시도하지 않는 편이 낫다.**

**(2) 유효한 손잡이는 지원자 배수 하나뿐이다.**
0.9 → 1.0에서 승률 2.1→3.6 / 폐원 34.3→23.4, 0.9 → 1.2에서 승률 14.0 / 폐원 5.4.
단조롭게 반응하고 부작용도 없다. 다만 **1.2까지 밀어도 편차는 29.8%p로 기준(15%p)을 못 맞춘다.**
그 지점에서 SELECTIVE의 배수는 FRANCHISE와 같아져 아키타입 정체성이 사라진다.

## 4. 제안 — 셋 중 하나를 골라 주십시오

### (가) D안 채택: 지원자 배수 0.9 → 1.2 — 권장
승률 14.0% / 폐원 5.4%. 판정 3은 여전히 실패지만 **"고르면 거의 확실히 지는 학원"은 사라진다.**
한 줄 상수 변경이라 되돌리기도 쉽다. 대신 "선발형은 지원자가 적다"는 설정은 포기하고,
화면 문구를 실제 동작(상위반 성적이 높고 폐원 위험이 낮다)에 맞춰 고쳐야 한다.

### (나) UI에서 SELECTIVE 제거, 2개로
밸런스 작업 0. 리스크 즉시 소멸. 학원 개성 한 축이 빠지고 콘텐츠 3종 배분도 흔들린다.
남은 두 개(50.1 / 30.5)의 편차는 19.6%p로 기준에 가깝다.

### (다) 규칙 변경: 상위반 실적을 자기지수에 직접 가산
근본 해법이다. SELECTIVE의 보상이 승리 지표에 직접 닿게 된다.
**다만 정산식 변경이고 P4 마지막 날이다.** 재측정·회귀 테스트가 다시 필요하고
프리즈(8/24)까지 4일 남았다. 권장하지 않는다.

## 5. 아무것도 안 하면

선발형을 고른 심사위원은 6턴 중 34% 확률로 폐원하고, 완주해도 98% 확률로 진다.
시연에서 이 학원을 고르는 순간 게임이 망가진 것처럼 보인다.
판정 3 실패는 리포트 맨 위 줄에 그대로 남는다.

## 6. 측정 재현

```
npm run --silent sim -- --games 100000 --seed 1 > sim.json
node scripts/report-balance.ts sim.json
```
각 안은 `src/core/balance.ts` 상수 한두 개만 바꿔 돌렸고 전부 원복했다.
