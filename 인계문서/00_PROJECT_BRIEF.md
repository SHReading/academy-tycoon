# 00. 프로젝트 브리프

> 가제: **학원 타이쿤 (Hagwon Tycoon)** — 재수학원 3파전 경영 시뮬레이션
> 대상: OpenAI Game Builders Seoul 2026, Track 1 온라인 예선 제출작
> 문서 상태: 초안 v0. 종이 프로토타입 검증 전까지 모든 수치는 가설.

---

## 1. 한 줄 정의

플레이어는 재수학원 하나를 맡아, 유한한 스타 강사를 두 경쟁 학원과 뺏고 뺏기며 3년 뒤 점유율 1위를 노린다.

## 2. 왜 이 소재인가

- **한국 관객에게 설명이 필요 없다.** 심사는 3분 엘리베이터 피치와 현장 시연으로 이뤄진다. "재수학원 원장"은 5초 안에 읽히는 몇 안 되는 소재다.
- **아트 부담이 0에 수렴한다.** 숫자·규칙·텍스트로 굴러가는 장르라 AI 구현에 가장 유리하다.
- **제작자만의 관점이 들어간다.** 강사 몸값과 실적의 관계, 반 편성 트레이드오프, 관리의 한계효용은 실제 시장을 파본 사람이 아니면 밸런스를 못 잡는다. Originality 축의 실질 근거.

## 3. 절대 가드레일 (위반 시 프로젝트 중단)

1. **실존 학원·강사·기업의 실명을 쓰지 않는다.** 아키타입만 차용하고 이름은 전부 가상. 게임 내 어디에도 실명 텍스트가 없어야 한다.
2. **회사 내부 데이터·문서·수치를 일절 반입하지 않는다.** 공개 정보와 일반 상식 수준의 구조만 사용한다.
3. 특정 실존 사업자를 열위로 묘사하는 표현을 넣지 않는다.
4. 이 저장소는 개인 프로젝트다. 업무 저장소·계정·자산과 분리한다.

## 4. 심사 기준 역산

공식 심사 항목은 5개다. 각 항목에 대해 이 프로젝트가 무엇으로 답하는지 미리 못 박는다.

| 심사 항목 | 이 프로젝트의 답 | 담보 방법 |
|---|---|---|
| Playability | 90초 안에 1턴이 돌고, 6턴이 5분 안에 끝난다 | 코어 루프 우선 개발, D7 플레이테스트 |
| Originality | 경영 시뮬 + 제로섬 강사 입찰 + 실제 시장 구조 | 입찰 메커닉을 코어에 배치 |
| Codex Collaboration | 코어 설계는 사람, 구현·콘텐츠 생산은 병렬 에이전트 | PR마다 결정/구현 분리 기록 (03 문서) |
| Release Potential | 랭킹·리플레이 공유 → 백엔드 연동 지점이 명확 | 점수 제출 인터페이스를 미리 추상화 |
| Presentation | 매 턴 결과가 신문 헤드라인 한 줄로 요약된다 | 헤드라인 시스템을 필수 기능으로 |

## 5. 성공 기준

- **최소 성공**: 8/26 이전에 로그인 없이 즉시 실행되는 웹 빌드 링크 제출 완료. (여기까지 오면 떨어져도 남는 게 있다)
- **목표**: 본선 40팀 진입.
- **부가**: Codex 병렬 생산 파이프라인이 재사용 가능한 형태로 남는다.

## 7. 스코프 가드

아래는 이번 제출작에 **넣지 않는다.** 유혹이 올 때마다 이 목록을 본다.
