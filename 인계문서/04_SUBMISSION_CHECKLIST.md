## 2. 플레이 링크 요건 (하나라도 실패하면 심사 불가)

- ☑ 브라우저에서 바로 실행되는 웹 빌드 — HTTP 200, 로딩 화면 없이 첫 화면 즉시 표시
- ☑ 심사 기간 내내 접속 가능 — GitHub Pages(공개 저장소), main 푸시마다 자동 재배포
- ☑ 별도 승인·로그인 없이 접근 가능
- ☑ 별도 제약 없이 플레이 가능
- ☑ 조작법과 실행 방법 안내가 게임 안에 있음 — 모든 버튼에 결과 설명이 한 줄씩 붙어 있다(예: "가장 높은 월급을 제시하면 영입하며, 그 월급은 매 학기 나갑니다")
- ☐ **시크릿 창에서 검증 완료** ← 사람
- ☐ **다른 기기 모바일에서 검증 완료** ← 사람

8/20 자동 브라우저로 390×844(모바일 세로)와 1440×900(데스크톱)에서 학원 선택 → 입찰 → 반 편성 → 정산까지 실제로 눌러 확인했다.
콘솔 오류는 favicon 404 하나였고 같은 날 고쳤다. 사람이 할 몫은 **실기기·시크릿 창** 두 줄만 남았다.

## 3. 가산점 항목 (선택이지만 반드시 낸다)

### 데모 영상 (3분 이내)
구성: 게임 소개 → 실제 플레이 → 핵심 기능. 실제 플레이 화면이 포함되어야 한다.

권장 배분
- 0:00–0:20 훅. "재수학원 원장이 되어 스타 강사를 뺏고 뺏긴다"
- 0:20–1:40 1턴 실제 플레이. 입찰에서 손이 멈추는 순간을 보여준다
- 1:40–2:30 6턴 압축, 헤드라인이 쌓이는 장면
- 2:30–3:00 개발 방식 한 컷 (병렬 트랙, 카드 생산 파이프라인)

### Codex 활용 설명
공식 질문 4개에 답하는 형식으로 쓴다. 03 문서의 PR 기록과 DEV_LOG에서 그대로 뽑는다.

- ☐ Codex를 어디에 사용했는가
- ☐ 어떤 기능을 구현했는가
- ☐ 어떤 문제를 해결했는가
- ☐ **사람이 직접 결정한 부분은 무엇인가** ← 여기가 차별점. 규칙 설계·밸런스 판정·스코프 컷이 전부 사람이었다는 점을 구체적 사례로 쓴다

## 4. 게임 소개 200자 초안

> 스타 강사는 한정되어 있고, 내가 지르지 않으면 경쟁 학원이 데려간다. 재수학원 세 곳이 같은 지원자를 놓고 3년간 경쟁하는 경영 시뮬레이션. 강사를 입찰로 영입하고, 네 개 반 중 어디에 배치할지 결정한다. 한 판 5분, 설치와 로그인 없이 브라우저에서 바로.

공백 포함 **146자** (8/20 실측, 제한 200자). 8/15 단순화로 반이 4개가 되어 "상위반과 중위반 중"을 "네 개 반 중"으로 고쳤다.

## 5. 3분 엘리베이터 피치 뼈대

| 구간 | 내용 |
|---|---|
| 0:00–0:20 | 한 문장 훅 + 왜 이 소재인지 (관객이 이미 아는 세계) |
| 0:20–1:20 | 라이브 시연. 입찰 한 번, 배치 한 번, 헤드라인 한 번 |
| 1:20–2:10 | 설계 관점. 제로섬 입찰이 왜 코어인지, 무엇을 일부러 뺐는지 |
| 2:10–2:50 | 개발 방식. 사람이 결정한 것과 병렬 생산으로 넘긴 것 |
| 2:50–3:00 | 확장 계획 한 줄 (랭킹·리플레이 연동 지점) |

**시연은 반드시 오프라인에서도 돌아가야 한다.** 현장 네트워크를 신뢰하지 않는다. 로컬 빌드를 노트북에 준비하고, 백업으로 화면 녹화본을 가져간다.

☑ **해결(8/22).** 일반 빌드는 `<script type="module" src="...">`라서 `file://`로 열면 CORS로 막힌다.
`npm run build`가 `dist/offline.html`(43KB, 외부 참조 0)을 함께 만들도록 했다. 더블클릭으로 실행되고
6턴 완주·콘솔 오류 0을 확인했다. 배포본에서도 받을 수 있다 — `/offline.html`.
**노트북에 이 파일 하나만 두면 된다.**

## 6. 제출 전 최종 점검 (8/25)

- ☐ **`schema/banned-terms.txt`가 비어 있다.** [1]~[4] 항목이 0개라 지금은 정규식 경고 규칙만 돈다.
  "사람이 직접 채운다"고 규정된 목록이므로 사람이 채운 뒤 `npm run validate:content`를 다시 돌려야 한다
- ☐ 실명 필터 최종 실행. 코드·콘텐츠·문서·영상 전체에 실존 학원/강사/기업명 0건
- ☐ 회사 데이터·내부 문서 흔적 0건
- ☐ 링크가 시크릿 창, 모바일, 다른 네트워크에서 열림
- ☐ 로딩 화면 없이 즉시 시작됨
- ☐ 게임 오버 후 재시작 동작
- ☐ 6턴 완주에 5분 이내
- ☐ 썸네일 16:9, 10MB 이하
- ☐ 데모 영상 3분 이내
- ☐ 저장소가 제출 후에도 유지됨 (링크 생존)
- ☐ 8/31 월요일 일정 확보
