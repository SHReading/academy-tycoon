# 05. P0 종이 프로토타입 키트

> 실행일: **8/11 (오늘)**. 소요 예상 40~60분.
> 목적: 코드 한 줄 쓰기 전에 **"지금 지를까 말까"로 손이 멈추는 순간이 3턴 안에 2회 이상** 발생하는지 확인한다.
> 이 게이트를 통과하지 못하면 P1로 넘어가지 않는다. (01 문서 8절)

## 0. 시작 전 — 사람이 결정해야 할 것 1건

**발견한 문제: 01 문서 6절 수치대로면 자금이 전혀 조이지 않는다.**

| 항목 | 문서값 | 결과 |
|---|---|---|
| 지원자 풀 | 턴당 300명, 3사 분할 | 학원당 약 100명 |
| 수강료 | 1인당 1 | 매출 약 100/턴 |
| 기본 운영비 | 20/턴 | 여유 약 80/턴 |
| 강사 요구 연봉 | (강의력+인지도)×3 → 7~29 | 매 턴 최고가 강사를 질러도 잔액이 남음 |

자금이 남으면 입찰이 **"항상 최대로 지르기"** 라는 지배전략이 되고, 코어 판타지인 제로섬 압박이 사라진다.
이는 01 문서 6절 검증 질문 1번(무입찰 전략이 지배전략인가)의 **반대편 실패 모드**다.

**제안 — P0에 한해 아래 값으로 테스트한다. 채택 여부는 사람이 결정한다.**

| 항목 | 문서값 | P0 테스트값 | 근거 |
|---|---|---|---|
| 수강료 | 1인당 1 | **1인당 0.5** | 매출 약 50/턴 → 운영비 20 제외 시 여유 30. 강사 1명 영입이 예산 대부분을 소모 |

밸런스 변경 권한은 사람에게 있다. (03 문서 1절 불변 규칙)
이 표는 제안이며, 승인 전까지 P0 시트의 수강료 칸은 비워둔다.

## 3. 학원 초기 상태

| | FRANCHISE | LEGACY | SELECTIVE |
|---|---|---|---|
| 시작 자금 | 100 | 70 | 50 |
| 시작 평판 | 40 | 60 | 45 |
| 성격 | 자금 최대, 평판 상승 둔함 | 평판 최대, 영입 매력 낮음 | 상위반 보정 큼, 자금 최소 |

**플레이어는 SELECTIVE를 잡는다.** 자금이 가장 빡빡해서 "지를까 말까"가 가장 자주 발생하는 자리이고, P0가 확인하려는 게 정확히 그 순간이기 때문이다.

**아키타입 보정 (P0 간이판)**

- FRANCHISE: 지원자 유입 +10%
- LEGACY: 평판 갱신 시 이전 평판 가중 0.8 (관성이 큼)
- SELECTIVE: 상위반 성적 ×1.3

## 4. AI 학원 2곳의 입찰 규칙 (손으로 굴리는 결정 규칙)

에이전트가 아니라 **표를 보고 기계적으로 따르는 규칙**이다. 매 턴 아래 순서대로 적용한다.

**공통**
1. 잔액이 요구연봉 미만인 카드에는 입찰하지 않는다.
2. 각 학원은 **턴당 최대 1명**만 영입한다.
3. 동액이면 평판이 높은 쪽이 가져간다.

**FRANCHISE** — 인지도를 산다
- 시장 4장 중 **인지도가 가장 높은 카드**를 목표로 한다.
- 입찰가 = 요구연봉 × **1.2** (소수점 올림)
- 잔액이 부족하면 그다음 인지도 카드로 내려간다.

**LEGACY** — 강의력을 산다
- 시장 4장 중 **강의력이 가장 높은 카드**를 목표로 한다.
- 입찰가 = 요구연봉 × **1.1** (소수점 올림)
- 잔액의 40%를 넘는 입찰은 하지 않는다.

**동점 처리**: 목표 카드가 여러 장이면 요구연봉이 낮은 쪽을 고른다.

**낙찰가는 이후 매 턴 고정비로 계속 빠진다.** 1턴에 29를 지르면 2턴·3턴에도 29가 나간다. 이게 P0가 검증하려는 긴장의 핵심이므로 절대 생략하지 말 것.

## 5. 턴 정산 시트 (간이판)

전체 7단계(01 문서 4절)를 손계산 가능하게 줄인 버전이다. **P1 엔진은 문서 원본 7단계를 구현한다.** 이 축약은 P0 전용이다.

### 단계 1 — 입찰
```
공개 카드 4장 기재 → 3사 동시 입찰가 기입 → 최고가 낙찰
낙찰가를 [고정비 누적] 칸에 더한다
```

### 단계 2 — 반 편성
```
보유 강사를 상위반 / 중위반 / 기초반에 배치
각 반은 국·수·영·탐 4슬롯. 빈 슬롯 1개당 −2
```

### 단계 3 — 운영 옵션 (택 1)

P0에서는 아래 3개로 축소한다.

| 옵션 | 효과 | 비용 |
|---|---|---|
| 담임 상담 확대 | 전 반 성적 +5% | 8 |
| 장학금 확대 | 다음 턴 지원자 +30% | 15 |
| 아무것도 안 함 | — | 0 |

### 단계 4 — 정산 (계산기)

```
① 반별 성적
   상위반 = (배치 강사 강의력 합 × 3 − 빈슬롯×2) × 아키타입 보정
   중위반 = (배치 강사 강의력 합 × 1 − 빈슬롯×2)
   기초반 = (배치 강사 강의력 합 × 1 − 빈슬롯×2)
   → 각 반에 운영 옵션 보정 적용

② 실적 점수 = 상위반 성적

③ 평판 = 이전 평판 × 0.7 + 실적 점수 × 0.3
   (LEGACY만 0.8 / 0.2)

④ 다음 턴 지원자
   자기 지수 = 평판 + (보유 강사 인지도 합 × 2)
   지원자 = 300 × (자기 지수 ÷ 3사 지수 합)
   → 옵션·아키타입 보정 적용, 반올림

⑤ 등록 인원 = min(지원자, 200)     ← 정원 합 상위40+중위80+기초80

⑥ 자금 = 이전 자금 + (등록 인원 × 수강료) − (강사 고정비 누적 + 운영 옵션 비용 + 20)

⑦ 점유율 = 자기 등록 인원 ÷ 3사 등록 인원 합
```

**이벤트 카드는 P0에서 돌리지 않는다.** 변수를 늘리면 무엇 때문에 재밌었는지/없었는지 판별이 안 된다.

### 기록 양식 (턴당 한 줄, 3사 × 3턴 = 9줄)

```
턴 | 학원 | 낙찰강사 | 낙찰가 | 고정비누적 | 상위반성적 | 평판 | 지원자 | 등록 | 자금 | 점유율
```

## 6. 통과 판정

플레이 중 아래를 **실시간으로 표시**한다. 끝나고 회상하면 부정확해진다.

### 주 기준 (01 문서 8절)
- ☐ 입찰가를 적기 전에 **5초 이상 손이 멈춘 순간**이 3턴 동안 **2회 이상** 발생했다

### 보조 관찰 항목 — 통과해도 아래를 기록해둔다

| 관찰 항목 | 예상되는 답 | 실제 |
|---|---|---|
| 3턴 내내 "최대한 지르기"가 정답이었는가 | 아니오여야 함 | |
| 3턴 내내 "아무것도 안 지르기"가 정답이었는가 | 아니오여야 함 | |
| 반 편성에서 고민이 발생했는가 | 예 (두 번째 딜레마) | |
| 1턴 소요 시간 | 손계산 5분 이내 | |
| 계산 중 "이 숫자는 왜 있지?" 싶은 항목 | 없어야 함 | |

### 불통과 시 (03 문서 1절: 판단은 사람이 한다)

1. **입찰이 안 조인다** → 수강료를 더 내리거나, 낙찰가 고정비를 6턴이 아니라 영구로 바꾼다
2. **입찰은 조이는데 지루하다** → 시장 공개 카드를 4장에서 3장으로 줄여 경합률을 올린다
3. **둘 다 실패** → 00 문서 8절 대응대로 **입찰만 남긴 초경량 버전**으로 재설계한다. 코드로 옮기지 않는다.
