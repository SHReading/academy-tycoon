# 01. 게임 디자인

문서 상태: v0 초안. **모든 수치는 검증 전 가설이며, 밸런싱 하네스 결과로 대체된다.**

---

## 1. 코어 판타지

"저 강사를 지금 지르지 않으면, 다음 학기에 저쪽 반이 꽉 찬다."

재미의 원천은 경영이 아니라 **제로섬 압박**이다. 강사 풀은 유한하고, 내가 안 가져가면 경쟁사가 가져간다. 모든 설계 판단은 이 압박을 강화하는가로 평가한다.

## 2. 승패 구조

- 1턴 = 1학기. 총 **6턴 (3년)**.
- 3개 학원이 같은 지원자 풀을 놓고 경쟁. 플레이어 1 + AI 2.
- 최종 승리 조건: **6턴 종료 시점 점유율 1위**.
- 조기 패배: 자금이 0 아래로 2턴 연속 유지되면 폐원.

## 3. 3개 학원 아키타입

이름은 전부 **가상 placeholder**다. 실존 학원명을 쓰지 않는다. (00 문서 가드레일 1)

| 코드명 | 성격 | 시작 강점 | 시작 약점 |
|---|---|---|---|
| `FRANCHISE` | 대형 프랜차이즈형 | 자금 최대, 지원자 유입 기본치 높음 | 평판 상승률 낮음, 고정비 큼 |
| `LEGACY` | 전통 명문 재수학원형 | 평판 최대, 이탈률 낮음 | 자금 보통, 신규 강사 영입 매력도 낮음 |
| `SELECTIVE` | 선발형 프리미엄 신흥 | 상위반 성적 보정 큼, 강사 영입 매력도 높음 | 자금 최소, 정원 작음 |

플레이어는 셋 중 하나를 고른다. 선택이 곧 난이도이자 전략이라 별도 난이도 설정을 두지 않는다.

## 4. 턴 구조 — 의사결정은 3개뿐

각 턴은 4단계로 진행되며, **플레이어가 누르는 버튼은 3단계까지 총 3회**다.

### 단계 1. 강사 영입 (블라인드 입찰)

- 매 턴 **강사 카드 4장**이 시장에 공개된다.
- 3개 학원이 동시에 비공개 입찰. 각 학원은 최대 1명까지 영입.
- 최고 입찰가 낙찰. 동액이면 **평판이 높은 쪽**이 가져간다.
- 낙찰가는 6턴간 매 턴 고정비로 빠진다. 지금의 지출이 아니라 **미래의 부채**라는 점이 핵심 긴장.
- 유찰된 강사는 다음 턴 시장에 재등장하며 요구 연봉이 25% 하락. (8/21 승인 — 후반 입찰 정체 대응)

**강사 카드 속성**

| 속성 | 값 | 효과 |
|---|---|---|
| 과목 | 국어 / 수학 / 영어 / 탐구 | 반 성적 계산의 과목 슬롯 |
| 강의력 | 1–5 | 배치된 반의 성적 상승 |
| 인지도 | 1–5 | 학원 전체 지원자 유입 증가 |
| 요구 연봉 | 정수 | 입찰 하한선 |
| 특성 | 1개 | 조건부 보정 (아래) |

**특성 예시** — 실제 카드는 배치 생산한다. (03 문서)
`상위반 특화` / `기초반 특화` / `언론 노출형(인지도↑ 강의력↓)` / `까다로움(평판 낮은 학원엔 입찰 무효)` / `사단형(같은 과목 동료 있으면 강의력+1)`

### 단계 2. 반 편성

보유 강사를 **상위반 / 중위반 / 기초반** 세 칸에 배치한다.

- **상위반** 배치 → 명문대 실적 가중 → 평판 상승폭 큼
- **중위반** 배치 → 등록 인원 가중 → 매출 큼
- **기초반** 배치 → 이탈률 감소

각 반은 과목 슬롯 4개(국·수·영·탐)를 가지며, 빈 슬롯은 성적에 페널티를 준다. 강사 수가 부족하면 어느 반을 포기할지 골라야 한다. **이것이 두 번째 딜레마다.**

### 단계 3. 운영 옵션 (택 1)

수업이 본체이고 관리는 얇게 얹는다. 매 턴 아래 중 **하나만** 켤 수 있고, 고정비가 발생한다.

| 옵션 | 효과 | 비용 |
|---|---|---|
| 자습 감독 강화 | 이탈률 −20% | 중 |
| 담임 상담 확대 | 성적 +5%, 평판 +소폭 | 중 |
| 장학금 확대 | 상위권 지원자 유입 +30% | 대 |
| 수강료 인상 | 매출 +25%, 지원자 유입 −15% | 없음(대신 평판 −) |
| 아무것도 안 함 | — | 없음 |

### 단계 4. 학기 정산 (자동)

플레이어 입력 없음. 결과가 **신문 헤드라인 3줄**로 뜬다.

```
정산 순서
1. 반별 성적 = Σ(강사 강의력 × 반 보정 × 아키타입 보정) − 빈 슬롯 페널티 + 운영 옵션 보정
2. 입시 실적 = f(상위반 성적, 상위반 인원)
3. 평판 갱신 = 이전 평판 × 0.7 + 실적 점수 × 0.3
4. 다음 학기 지원자 유입 = 기본치 × (평판 계수) × (인지도 합 계수) × (옵션 보정)
5. 자금 = 이전 자금 + (등록 인원 × 수강료) − (강사 고정비 + 운영 고정비 + 기본 운영비)
6. 점유율 = 자기 등록 인원 / 3사 합계
7. 이벤트 카드 1장 발동
```

### ★ 8/15 단순화 개정 — 아래 계산식보다 이 절이 우선한다

**대상 이용자를 10대 중반~30대 초반 캐주얼로 확정했다.** 5분 안에 어렵지 않게 즐기는 게 목표다.
지금 한 턴에 12슬롯 배치 + 옵션 5개 + 지표 7개를 처리하게 되어 있어 과하다.
**새 규칙을 만들지 않고 덜어내는 방향으로만 고친다.**

| 항목 | 이전 | 개정 |
|---|---|---|
| 반 편성 | 3반 × 과목 4칸 = **12슬롯** | **반 4개에 강사를 넣기만 한다.** 과목 칸 없음 |
| 반 종류 | 상위 / 중위 / 기초 | **상위 / 중상위 / 중위 / 기초** |
| 반당 강사 | 과목별 1명 (4명) | **2명** |
| 빈 슬롯 페널티 | 슬롯당 −2 | **삭제.** 강사 없는 반은 성적 0 |
| 성적 계수 | 상위 ×3, 나머지 ×1 | 상위 ×3 / 중상위 ×2 / 중위 ×1.5 / 기초 ×1 |
| 반 정원(학생) | 40 / 80 / 80 | **40 / 60 / 60 / 40** (합 200 유지) |
| 운영 옵션 | 5개 | **3개** — 자습 감독 강화 / 장학금 확대 / 아무것도 안 함 |
| 특성 | 6종 | **3종** — `CLASS_SPECIALIST`(배치된 반 실력 +1) / `MEDIA_FIGURE` / `FACTION` |
| 화면 숫자 | 7개 | **3개** — 돈 / 매 학기 월급 / 학생 점유 |

`PICKY`와 반별 특화 3종은 삭제한다. 조건이 붙은 특성은 캐주얼에게 읽히지 않는다.
평판은 계산에는 남기되 **화면에는 별 5개로만** 보여준다.

과목(`subject`)은 카드에 그대로 두되 **게임 규칙에서는 쓰지 않는다.** 분위기용 표시다.
덕분에 기존 강사 카드 40장을 다시 만들 필요가 없다 — 특성만 3종으로 재배정한다.

**용어를 쉬운 말로 바꾼다.** 화면·헤드라인 모두 오른쪽 말을 쓴다.

| 지금 | 바꿈 |
|---|---|
| 강의력 | 실력 |
| 인지도 | 유명세 |
| 요구 연봉 / 최소 입찰 | 원하는 월급 |
| 낙찰가 / 고정비 | 매 학기 월급 |
| 평판 | 학원 인기 (별 5개) |
| 점유율 | 학생 점유 |
| 학기 정산 | 학기 결과 |

**바꾸지 않는 것**: 6턴, 블라인드 입찰, 낙찰가가 6턴간 매 턴 빠지는 구조, 헤드라인 3줄, 승패 조건.
이 넷이 이 게임에서 가장 잘 작동하는 부분이다.

### 정산 계산식 확정본 (8/13 사람 승인)

상수는 전부 `src/core/balance.ts` 한 파일에 둔다. **이 값들은 가설이고, 트랙 D 시뮬이 검증한다.**
근거와 대안은 `docs/BALANCE_PROPOSAL.md`.

```
① 반별 성적
   상위반 = (Σ강의력 × 3 − 빈슬롯 × 2) × 아키타입보정_성적
   중위반 = (Σ강의력 × 1 − 빈슬롯 × 2)
   기초반 = (Σ강의력 × 1 − 빈슬롯 × 2)
   → 운영 옵션 성적 보정 적용

② 입시 실적 = 상위반 성적 × min(1, 상위반 인원 ÷ 40)

③ 평판 = 이전 평판 × 0.7 + 실적 × 0.3        (LEGACY만 0.8 / 0.2)

④ 지원자 = 300 × (자기지수 ÷ 3사 지수합) × 아키타입보정_지원자 × 옵션보정
   자기지수 = 평판 + (보유 강사 인지도 합 × 2)

⑤ 이탈률 = max(0.05, 0.20 − 기초반 성적 × 0.005)   → 자습감독 시 ×0.8
   등록 인원 = min(지원자 × (1 − 이탈률), 200)      ← 반 정원 합이 상한

⑥ 자금 = 이전 자금 + (등록 인원 × 0.5) − (강사 고정비 + 운영 고정비 + 14)

⑦ 점유율 = 자기 등록 인원 ÷ 3사 합계

⑧ 이벤트 카드 1장 발동 — 효과는 **다음 턴 계산에 반영**한다
   (정산 도중 값이 바뀌면 헤드라인과 숫자가 어긋나 화면에서 인과가 안 읽힌다)
```

| 아키타입 | 성적 보정 | 지원자 보정 | 평판 갱신 |
|---|---|---|---|
| FRANCHISE | 1.0 | 1.2 | 0.7 / 0.3 |
| LEGACY | 1.2 | 1.0 | **0.8 / 0.2** |
| SELECTIVE | 1.1 | 0.9 | 0.7 / 0.3 |

| 운영 옵션 | 효과 | 비용 |
|---|---|---|
| 자습 감독 강화 | 이탈률 ×0.8 | 8 |
| 담임 상담 확대 | 성적 ×1.05, 평판 +2 | 8 |
| 장학금 확대 | 지원자 ×1.3 | 15 |
| 수강료 인상 | 매출 ×1.25, 지원자 ×0.85, 평판 −3 | 0 |
| 아무것도 안 함 | — | 0 |

## 5. 헤드라인 시스템 (Presentation 담보 장치)

매 턴 정산 후, 상황을 **문장 3줄**로 요약해 신문 톤으로 띄운다. 숫자 표가 아니라 이것이 플레이어의 주된 정보원이다.

```
[3월] 「OO강사, 경쟁 학원으로 전격 이적」
[3월] 「신흥 학원, 상위반 정원 조기 마감」
[3월] 「수강료 인상 여파… 학부모 게시판 술렁」
```

시연에서 관객이 규칙을 몰라도 상황을 이해하게 만드는 장치다. **필수 기능이며 P2에 포함한다.**

## 7. UX 원칙 (타협 불가)

1. **로딩 화면 없음.** 링크 클릭 즉시 첫 화면.
2. **1턴 90초, 1판 5분 이내.**
3. **튜토리얼 없음.** 버튼에 붙은 한 줄 설명으로 이해되어야 한다.
4. **모바일 세로 화면 대응.** 현장 인기 투표는 참석자 휴대폰에서 일어난다.
5. 한 화면에 동시에 보이는 숫자는 **7개 이하**.
6. 게임 오버 후 **한 번의 탭으로 재시작**.

## 8. P0 종이 프로토타입 (착수 전 필수)

코드 한 줄 쓰기 전에 반나절로 확인한다.

**준비물**: 인덱스카드 12장(강사), 종이 3장(학원판), 계산기

**절차**
1. 강사 카드 12장을 만든다. 강의력/인지도/요구연봉만 적는다.
2. 3턴만 돌린다. 경쟁 학원 2곳은 "요구 연봉의 1.2배까지 입찰" 같은 단순 규칙으로 대신한다.
3. 매 턴 입찰 → 배치 → 정산을 손으로 계산한다.

**통과 기준**: 3턴 안에 **"지금 지를까 말까"로 손이 멈추는 순간이 최소 2회** 발생한다.
**불통과 시**: 코드로 옮기지 않는다. 입찰만 남긴 초경량 버전으로 재설계하거나 소재를 바꾼다.
